# Personal Contact Management System
Description
A console-based Contact Management System built using Python that allows users to manage contacts efficiently using data structures and OOP concepts.
Features
- Add new contacts  
- View all contacts  
- Search contacts by name or phone  
- Update contact details  
- Delete contacts  
- Prevent duplicate phone numbers  
Tech Stack
- Python  
- Object-Oriented Programming (OOP)  
- Data Structures (Lists, Dictionaries, Sets)
